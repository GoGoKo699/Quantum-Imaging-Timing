# Background and derivation route

This directory connects the quantum imaging framework to the project's theorem for a Brownian moving source pair. It uses one background anchor: Mankei Tsang's [*Resolving starlight: a quantum perspective*, accepted arXiv version 2](https://arxiv.org/pdf/1906.02064v2).

1. [TSANG_BRIDGE.md](TSANG_BRIDGE.md) maps the relevant source sections, translates the PSF and separation conventions, distinguishes mean photon number from supplied photon count, and constructs the correlated Brownian state. Its worked pair example explains the zero-motion null, the Brownian background and the change in testing scale.
2. [MILESTONES.md](MILESTONES.md) organizes the mathematical preparation and the scientific argument, including the steps that require local proofs beyond the anchor.
3. [The scientific account](../science/README.md) contains the canonical theorem, receiver, collective converse, timing consequences and physical assumptions. Those files remain authoritative for the formal claims.

The central destination is a fixed-error law for the complete timestamped quantum record. The source's Fisher-information framework supplies useful background, while the project proves its testing guarantees using state distances, pair affinities and the Brownian covariance structure.

The background anchor does not replace primary attribution. [Related work](../references/related-work.md) and [references.bib](../references/references.bib) identify the inherited results and the precise contribution of the timing theorem.
